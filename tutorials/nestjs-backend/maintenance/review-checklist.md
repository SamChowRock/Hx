# 教程语义审查清单

> [返回维护说明](README.md) · [返回教程首页](../README.md)

影响检查只能定位候选章节。更新教程时，至少确认：

## 代码事实

- 教程中的文件路径、类名、Service 名和命令仍然存在；
- 环境变量、默认值和启用条件与运行时 Schema 一致；
- API Method、路径、状态码、Cookie、Header 和错误语义一致；
- Prisma Model、字段、关系、约束、索引和 Migration 顺序一致；
- Compose 的端口、Volume、依赖、健康检查和安全选项一致。

## 设计解释

- 原先解释的“不变量”是否仍成立；
- 信任边界、授权边界或事务边界是否变化；
- 新实现是否增加并发窗口、重试、幂等或一致性要求；
- 失败模式、恢复方式和可观测性是否变化；
- ADR 已改变时，教程是否仍在解释旧决策。

## 实验

- 命令能在当前工具链版本运行；
- 实验只操作本地或隔离资源；
- 操作步骤、预期现象和恢复步骤完整；
- 破坏性命令具有明确目标和风险提示；
- 预期输出不是从旧版本复制而来。

## 验证证据

- 自动生成事实已经更新；
- `pnpm tutorial:check` 通过；
- 相关单测/E2E 通过；
- Docker/数据库变化完成对应 smoke test 或恢复演练；
- PR 描述说明更新了哪些章节，或为什么无需正文变更。
